Message WhatsApp des bons plans

Page privée (non référencée) : elle prépare le message de la semaine avec les vrais prix repérés, prêt à coller dans la chaîne WhatsApp Escale.

Ouvrir la chaîne WhatsApp
Pour publier
  1. Choisissez la ville de départ, puis « Préparer le message ».
  2. Relisez le message (vous pouvez le modifier), puis « Copier ».
  3. Dans WhatsApp : onglet Actualités → votre chaîne Escale → collez et envoyez.
